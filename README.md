# 《电路分析 A》交互式教学仿真与演示平台 (ngspice WebAssembly)

本项目根据深圳技术大学中德智能制造学院 **《电路分析 A (SG00379)》课程教学大纲**（配套推荐教材：邱关源、罗先觉《电路（第 6 版）》）设计与开发，基于运行在浏览器本地的 **ngspice WebAssembly (`eecircuit-engine`)** 电路仿真引擎，支持零后端静态部署至 **GitHub Pages**。

## 功能亮点

1. **按章节下拉菜单联动选择案例**：
   - 顶部导航栏提供 **【按章节选择】** 与 **【本章教学案例】** 双下拉菜单联动切换，并配有 **【教学大纲全览】** 矩阵面板与 `#case=...` 锚点直达链接（便于教师在 PPT 或课程群中直接分享指定教学案例链接）。
2. **全大纲教学内容与必做实验 100% 覆盖（共 12 个模块、43 个典型交互仿真案例）**：
   - **第一章：电路模型和电路定律**（参考方向与功率平衡、线性电阻伏安特性、电压源/电流源外特性、VCVS/VCCS/CCVS/CCCS 四种受控源、KCL 与 KVL 验证）
   - **第二章：电阻电路的等效变换**（串并联分压分流、不平衡电桥 Y-Δ 等效变换双网表核验、实际电源两种模型等效变换、含受控源输入电阻与负电阻演示）
   - **第三章：电阻电路的一般分析方法**（连通图与生成树 T 切换及独立方程数、支路电流法、网孔/回路电流法含无伴电流源处理、改进节点电压法 MNA）
   - **第四章：电路定理**（叠加定理三网表同步仿真及功率不可叠加性、替代定理电压源/电流源双替代、戴维南与诺顿定理三网表验证、最大功率传输 `.dc RL` 电阻扫描与效率曲线）
   - **第六章：储能元件**（电容 VCR 微分关系与电场储能、电感 VCR 微分关系与磁场储能、电容与电感串并联分压/等效对比）
   - **第七章：一阶电路的时域分析**（换路定则与初始值跃变分析、零输入响应与时间常数 $\tau$、RC/RL 零状态响应、全响应分解与三要素法）
   - **第八章：相量法**（复数与正弦量三要素及旋转相量合成、R/L/C 基本元件相量 VCR 与相量 KVL 勾股验证）
   - **第九章：正弦稳态电路的分析**（复阻抗/复导纳与相量图、有功/无功/视在功率与并联电容提高功率因数节能演示、共轭匹配与模匹配最大功率传输曲线）
   - **第十章：含有耦合电感的电路**（互感同名端顺接/反接去耦计算、空心变压器反射阻抗与理想变压器阻抗变换）
   - **第十一章：电路的频率响应**（网络函数与 RC 低通/高通/带通波特图、RLC 串联谐振与过电压品质因数 $Q$、RLC 并联谐振选频与支路过电流）
   - **第十二章：三相电路**（对称三相 Y/Δ 联接线相 $\sqrt{3}$ 与 $30^\circ$ 关系、不对称三相电路与中线断路过压故障安全警示、三相瞬时功率恒定与二瓦计法测功率）
   - **课内实践（18 学时 · 6 个必做实验项目）**：实验一（信号发生器 50Ω 内阻与示波器/万用表测量）、实验二（线性电阻与 1N4148 二极管非线性伏安特性）、实验三（基尔霍夫定律与叠加定理完整数据表）、实验四（戴维南外特性测绘与半电压法）、实验五（方波 RC 微分电路与积分电路）、实验六（RLC 并联交流特性与电流相量三角形综合实验）。
3. **开放式 SPICE 网表工作台**：
   - 每个案例均实时展示底层标准 SPICE 网表（`.op`、`.dc`、`.tran`、`.ac`、`K` 耦合电感、受控源、半导体 `.model` 等），支持课堂现场修改网表语句并重跑 `ngspice WASM` 求解。

## 本地运行与构建

确保已安装 Node.js（建议 v20+）：

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器
npm run dev

# 3. 构建静态生产包（输出至 dist/ 目录）
npm run build
```

## 发布到 GitHub Pages 指南

本项目已在 `vite.config.ts` 中配置相对路径 `base: './'`，并在 `public/.nojekyll` 及 `.github/workflows/deploy.yml` 中内置了自动化部署配置，无论是部署在主域名还是任意子仓库路径（如 `https://<用户名>.github.io/<仓库名>/`）均可直接运行：

1. 在 GitHub 新建仓库并将本文件夹代码推送到 `main` 分支：
   ```bash
   git init
   git add .
   git commit -m "feat: 初始化电路分析A ngspice wasm 教学仿真网站"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<你的仓库名>.git
   git push -u origin main
   ```
2. 进入 GitHub 仓库页面，依次点击 **Settings** → **Pages**。
3. 在 **Build and deployment** 下的 **Source** 下拉框中选择 **GitHub Actions**。
4. Actions 工作流将自动完成构建与发布（约 1 分钟），完成后即可通过页面显示的 GitHub Pages 网址访问教学平台！
